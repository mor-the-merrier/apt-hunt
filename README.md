# 🏠 סוכן מודעות דירות – סיכום יומי לטלגרם

כל ערב הסוכן סורק קבוצות פייסבוק ציבוריות ומחלץ מכל מודעה חדרים, מחיר, ממ"ד ומיקום. אחר כך הוא שולח לטלגרם שני דברים:

1. **הודעה קצרה** עם המספרים ועם עד 5 המודעות הכי מתאימות.
2. **קובץ HTML** עם שני טאבים:
   - **כל הדירות – 24 שעות:** כל מודעות המכירה החדשות, מהחדשה לישנה. מודעות השכרה ו"מחפשים דירה" מסוננות החוצה.
   - **לפי הפילטר:** 3–4 חדרים, ממ"ד, עד 2.8 מיליון ₪. בטאב הזה יש גם חלק של "אולי מתאימים", עם מודעות שחסר בהן מידע.

לוחצים על הקובץ בטלגרם והוא נפתח בדפדפן של הטלפון. לכל מודעה יש קישור לפוסט, ואפשר לפתוח בה את הטקסט המקורי.

```
GitHub Actions (כל ערב) → Apify (איסוף) → ניקוי כפילויות → Gemini (חילוץ) → פילטר → Telegram
```

## התקנה (פעם אחת, בערך 20 דקות)

### 1. בוט טלגרם
1. בטלגרם פותחים שיחה עם **@BotFather**, שולחים `/newbot` ובוחרים שם. שומרים את ה-**token** שמתקבל.
2. אם רוצים שהסיכום יגיע לקבוצה: יוצרים קבוצה ומוסיפים אליה את הבוט. אחרת פשוט שולחים לבוט הודעה בשיחה פרטית.
3. שולחים הודעה כלשהי בקבוצה (או לבוט), ואז פותחים בדפדפן:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
   בתשובה מופיע `"chat":{"id": ...}`. זה ה-**chat id**. בקבוצות הוא מתחיל במינוס.

### 2. Apify (איסוף הפוסטים)
1. נרשמים ב-apify.com. התוכנית החינמית לא דורשת כרטיס אשראי.
2. ב-**Settings → API & Integrations** מעתיקים את ה-**API token**.
3. ה-Actor שבשימוש הוא `memo23/facebook-public-group-posts-scraper`. הוא עולה בערך $1.5 לכל 1,000 פוסטים, ונכנס בתוך הקרדיט החינמי של $5 לחודש (ראו "עלויות" למטה).

### 3. Gemini (ניתוח המודעות)
1. נכנסים ל-aistudio.google.com עם חשבון גוגל.
2. לוחצים **Get API key → Create API key** ומעתיקים את המפתח. המכסה החינמית מספיקה לשימוש כזה.

### 4. GitHub
1. יוצרים **מאגר פרטי** (private repo) חדש ומעלים אליו את כל הקבצים שבתיקייה הזו.
2. ב-**Settings → Secrets and variables → Actions → New repository secret** מוסיפים ארבעה סודות:
   | שם | ערך |
   |---|---|
   | `APIFY_TOKEN` | ה-token מ-Apify |
   | `GEMINI_API_KEY` | המפתח מ-AI Studio |
   | `TELEGRAM_BOT_TOKEN` | ה-token מ-BotFather |
   | `TELEGRAM_CHAT_ID` | ה-chat id |
3. מוסיפים את הקבוצות לקובץ `config.yaml`, תחת `groups`.
4. בלשונית **Actions** בוחרים **Daily apartment digest → Run workflow**. הסיכום הראשון אמור להגיע לטלגרם תוך כמה דקות.

מכאן והלאה הסוכן רץ לבד כל ערב ב-18:00 שעון ישראל, גם בשעון חורף וגם בשעון קיץ. הריצות של GitHub לפעמים מתעכבות בכמה דקות. השעה מוגדרת ב-`.github/workflows/daily.yml`.

## שינוי הפילטר
כל הפרמטרים נמצאים ב-`config.yaml`, תחת `filter`: טווח חדרים, מחיר מקסימלי, האם ממ"ד הוא חובה, רשימת ערים, והאם לסנן מתווכים. השינוי נכנס לתוקף בריצה הבאה.

## עלויות ומגבלות
- **Apify:** הקרדיט החינמי ($5 לחודש) מספיק לבערך 3,000 פוסטים בחודש, כלומר כ-100 ביום. `max_posts_per_group` ב-config מגביל את מספר הפוסטים מכל קבוצה. אם הקרדיט נגמר, Apify פשוט עוצר עד החודש הבא ולא מחייב. הסוכן ישלח הודעת שגיאה לטלגרם.
- **Gemini:** חינמי. אם המודל לא זמין, הסוכן עובר לחילוץ בסיסי עם regex ומציין את זה בסוף ההודעה.
- **GitHub Actions:** חינמי. ריצה אחת לוקחת כמה דקות.
- ה-Actor עובד רק על **קבוצות ציבוריות**. גירוד מפייסבוק נוגד את תנאי השימוש שלה. כאן הסריקה נעשית דרך שירות חיצוני, ולא דרך החשבון הפרטי שלכם.

## בדיקה מקומית
```bash
pip install -r requirements.txt
python src/main.py --input samples/sample_posts.json --dry-run --no-llm
```
`--dry-run` לא שולח כלום: הוא מדפיס את ההודעה ושומר את הדוח בתיקייה `out/`. `--no-llm` מדלג על Gemini.

## מבנה הקבצים
| קובץ | תפקיד |
|---|---|
| `src/collect.py` | הרצת Apify ונרמול הפוסטים |
| `src/extract.py` | חילוץ שדות עם Gemini, ו-regex כגיבוי |
| `src/filters.py` | הפילטר: מתאים / אולי / לא |
| `src/html_report.py` | דוח ה-HTML עם הטאבים |
| `src/report.py` | שליחה לטלגרם |
| `src/main.py` | הרצה מקצה לקצה, כולל ניקוי כפילויות |
| `state/seen.json` | פוסטים שכבר דווחו (מתעדכן אוטומטית) |
